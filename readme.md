# Core Java Practice Problems

Just a repo where I'm storing my solutions for some Java practice problems. It's helping me get a better grip on the fundamentals.

## How it's organized

*   `Programming-Elements`: The real basics, like variables, operators, and input/output.
*   `Control_Flow`: All about `if` statements, `for`/`while` loops, and `switch` cases.
*   `Arrays`: Problems that need arrays to solve them.
*   `JavaMethods`: Exercises on creating and using methods.

Inside each of these folders, you'll find different levels (`Level-1`, `Level-2`, etc.)
